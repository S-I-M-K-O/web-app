Pizza Rating


┬

| STATUS: DONE

| LAST UPDATE: MAY 2026

┴


[+] Short summary:


For our DND sessions we needed a shared pizza rating page. Every game night ends in the same debate about which pizzeria actually delivers, so I built a simple page the whole group can use from their phones - everyone rates the pizza, the page keeps the score.


[+] Problem:


Game night, everyone hungry, nobody can remember which pizzeria was actually good last time. Opinions are loud, memories are short, and the group always ends up ordering from the same place out of habit.


[+] Solution:


A small app that runs on the LAN and is reachable from every phone in the room. The stack:

┬

├─ Go backend - HTTP API, serves ratings from data.json

├─ data.json - persistent storage backed by a Docker volume

├─ Plain HTML/CSS/JS - mobile-first frontend, no framework

├─ Real-time updates - new ratings appear on every device instantly

├─ Smart sorting - pizzerias ranked by highest score

└─ docker compose - one command, up and running


Rate a pizzeria from 1 to 6, drop an optional comment, and the list re-sorts itself on the fly. Duplicate pizzeria names get normalized automatically, so "Pizza Napoletana" and "pizza napoletana" don't split the votes.


[+] Lessons learned:


Keep it boring and it just works. A Go server, a JSON file and a bit of plain JavaScript covered everything the group needed - no database, no frontend framework, no over-engineering. The data outlives the sessions because it persists in a Docker volume.

Next time I would add live-update via WebSockets instead of polling, so a new rating appears even on a phone sitting in another room while the game is still running.
