Kubernetes Cluster Creation with Kubespray

┬

| 16. OCT 2024

┴

[+] Short summary:


Developed and implemented an Terraforn/GitLab CI/CD pipeline to automatically deploy a Hetzner server cluster, with a fully bootstrapped Kubernetes cluster using Kubespray.


[+] Problem:


So Kubernetes clusters out of the box - sounds super cool. But if you want to do it on your own there are not so many good working soultions.

Additionally to this if you want to use the Hetzner Cloud because, of financial purposes mostly, there are almost no solutions.


[+] Solution:


But here comes KUBESPRAY. Making our (or at least my) lives better.

So as a DevOps I wanted to try this out and have created a Project for testing.



My goal was to Create a cool cluster setup with terraform Gitlab-CI/CD-Pipelines and Kubespray and let it run on the Hetzner Cloud. So the first thing that was important was to create the nessesary terraform files.

┬

├─ provider.tf

├─ backend.tf

├─ main.tf

├─ variables.tf

└─ outputs.tf


I think the thing that was hardest was to get used to the hetzner terraform provider.
Regarding the fact that it is not used by many people, I understand that it is a little bit unsophisticated. The good nows is: You'll get used to it. The outputs file gives us the ip adresses of the nodes, so we can connect to them and access the masternode.
